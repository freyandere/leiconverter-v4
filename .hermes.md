# .hermes.md — LeiConverter v4

## Design Principles
1. **Offline-first caching**: Room stores last known rates; app works with cached data when offline
2. **Cross-rate via MDL base**: BNM only gives rates to MDL; cross-rates computed as `Rate(A/MDL) / Rate(B/MDL)`
3. **Real-time conversion**: No debounce on conversion; immediate recalculation on every keystroke

## Constraints
- MVP uses `fallbackToDestructiveMigration()` for Room
- No WorkManager on MVP (update on app open only)
- No math operators on Numpad (digits + dot + backspace only)
- Rate list always shown in MDL base
- Vico sparkline requires fade animation (200ms) on load

## Key Pitfalls
- BNM XML: nominal may differ from 1 (e.g., Nominal=100 USD); always divide: `realRate = value / nominal`
- BNM XML: weekends/holidays return last working day rate (not error)
- XmlPullParser: handle multiple Record elements, CharCode may repeat
- Cross-rate: EUR→USD = EUR_rate / USD_rate (both relative to MDL)
- Swap: use IconButton, not FAB (too aggressive for this operation)

## Code Style
- Kotlin 1.9+, Coroutines + Flow
- Compose: declarative only, no imperative DOM-like updates
- ViewModel: single responsibility, no UI logic
- Naming: camelCase for variables, PascalCase for classes, SCREAMING_SNAKE for constants
- Package: com.leiconverter (no hyphens — Android convention)
