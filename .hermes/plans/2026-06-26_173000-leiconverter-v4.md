# LeiConverter v4 — Project Plan

## Goal
Android currency converter with Material 3 UI, real-time BNM exchange rates, cross-rate calculation, and 30-day volatility chart.

## Architecture
MVVM (Model-View-ViewModel) with Unidirectional Data Flow:
- UI Layer: Jetpack Compose (Material 3, dynamic colors)
- Presentation: ViewModel + StateFlow
- Data: Room (caching) + Retrofit (BNM XML)
- Charts: Vico (sparkline)
- DI: Hilt

## Tech Stack
| Layer | Tech |
|-------|------|
| UI | Jetpack Compose (Material 3) |
| State | ViewModel, StateFlow |
| Network | Retrofit 2 + OkHttp3 + kotlinx-serialization |
| Parsing | XmlPullParser (BNM XML) |
| DB | Room |
| Charts | Vico (sparkline) |
| DI | Hilt |
| Background | WorkManager (post-MVP) |

## Key Features
1. Custom in-app Numpad (no system keyboard)
2. Real-time conversion (onValueChange, no debounce)
3. Swap button with rotation animation
4. Cross-rate calculation (EUR→USD via MDL base)
5. BNM XML API integration for current + historical rates
6. Room caching with Stale-While-Revalidate
7. 30-day volatility chart (Vico sparkline)
8. Offline fallback to last-cached rates

## Constraints
- No offline-first for history (XML fetches 30 days only on-demand)
- No math operators on Numpad (digits + dot + backspace only)
- Rate list always shown in MDL base (dynamic cross-rate in UI only)
- MVP: `fallbackToDestructiveMigration()` for Room
- No WorkManager on MVP (update on app open only)

## Design Tokens (from index-dark.html)
- Background: #0A0A0A, Surface: #111111, Variant: #1A1A1A
- Accent: #F0AD4E, Rate: #4A9EFF, Alert: #E74C3C
- Card radius: 36dp, Chip radius: 8dp
- Grid: 8dp / 16dp

## Pitfalls
- BNM XML: nominal may differ from 1 (e.g., Nominal=100 USD); realRate = value / nominal
- BNM XML: weekends/holidays return last working day rate, not error
- XmlPullParser: handle multiple Record elements, CharCode may repeat (historical)
- Cross-rate math: EUR→USD = EUR_rate / USD_rate (both relative to MDL)
- Room: use `fallbackToDestructiveMigration()` on MVP
- Vico sparkline: add fade animation (200ms) on data load
- Swap: use IconButton, not FAB (too aggressive)

## Libraries
- BNM API: `bnm.md/ru/official_exchange_rates?get_xml=1&date=DD.MM.YYYY`
- Vico charts: `com.patrykandpatrick.vico:compose-m3:1.19.0`
- Retrofit: `com.squareup.retrofit2:retrofit:2.11.0`
- Room: `androidx.room:room-runtime:2.6.1`
- Hilt: `com.google.dagger:hilt-android:2.51.1`
- kotlinx-serialization: `org.jetbrains.kotlinx:kotlinx-serialization-json:1.7.1`
